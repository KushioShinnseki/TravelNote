# TravelNote 微信小程序

本目录是微信开发者工具可直接导入的离线小程序源码。

使用方式：

1. 用微信开发者工具导入 `miniapps/wechat`。
2. 将网页端部署后登录，在“离线交换”生成二维码。
3. 在小程序点击“扫码同步数据”。

首次扫描会绑定二维码中的 `accountId`。之后只接受同一账号 ID 的数据包；同一账号的地点和日程按记录 ID 做新建、更新和删除同步。设置页的“清空本地数据并重新绑定”按钮只清除手机缓存，不会影响网页端数据库。

发布前请在微信开发者工具中填写自己的 AppID；`project.config.json` 的 `touristappid` 仅用于本地预览。
